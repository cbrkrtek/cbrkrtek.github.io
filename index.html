// About Me

I started in a SOC — SIEM, MITRE ATT&CK, EDR, incident response — and got good at spotting things that had already gone wrong. At some point I realized I'd rather stop them from going wrong in the first place. That is what pulled me into DevSecOps: securing the pipeline itself, before code ever gets near production.

Most of my work lives at the intersection of CI/CD, cloud infrastructure, and Kubernetes. I build GitHub Actions pipelines where security gates actually block the build — Bandit (SAST), Trivy (SCA/SBOMs), Gitleaks (Secrets), ZAP (DAST). On IaC, I write Terraform with security as default: remote state locking, OIDC auth, and plan-on-PR GitOps.

Kubernetes is where I spend most of my time lately. I harden clusters from the ground up — RBAC least-privilege, NetworkPolicy segmentation, Kyverno admission policies, securityContext controls, and Pod Security Standards.

The SOC background shapes how I build: I don't build controls to check a compliance box — I build them around how attackers actually move through a system. Everything I build is public on GitHub, documented start to finish.
